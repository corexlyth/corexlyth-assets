# CoreXLyth Assets

CoreXLyth blogunda kullanılan kapak görselleri, rehber ekran görüntüleri ve diğer görsel varlıkların barındırıldığı depodur.

Bu depo, Blogger içeriklerinde kullanılan görselleri GitHub Pages üzerinden yayınlamak ve görsel kaynaklarını düzenli biçimde kayıt altında tutmak amacıyla kullanılır.

## Kaynak ve üretim bilgileri

Her görselin kaynağı, üretim yöntemi ve gerektiğinde üçüncü taraf lisans bilgileri:

`SOURCES.md`

dosyasında tutulur.

## GitHub Pages

Ana adres:

https://corexlyth.github.io/corexlyth-assets/

Blog içeriklerinde kullanılan dosyalar ilgili klasörlerinden doğrudan servis edilir.

## Not

Üçüncü taraf uygulama adları, logoları, arayüzleri ve markaları ilgili hak sahiplerine aittir. Bu depoda yer alan ekran görüntüleri CoreXLyth rehberlerini açıklamak amacıyla kullanılmaktadır.
